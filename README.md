# កម្មវិធីទាញយកវីដេអូ (Android)

កម្មវិធី Android សម្រាប់ទាញយកវីដេអូ/សំឡេង ពី YouTube, TikTok និងគេហទំព័រផ្សេងៗដែល yt-dlp គាំទ្រ។

## មុខងារ
- បិទភ្ជាប់តំណច្រើន (មួយបន្ទាត់មួយតំណ) ឬបន្ថែមពី Clipboard
- ចុច **Share** ពីកម្មវិធី TikTok / YouTube ហើយជ្រើស "ទាញយកវីដេអូ" ដើម្បីបន្ថែមតំណចូលបញ្ជី
- ទាញយកទាំងអស់តាមលំដាប់ មើលស្ថានភាពនិងភាគរយនីមួយៗ ហើយអាចបញ្ឈប់បាន
- ជ្រើស MP4 (វីដេអូ) ឬ MP3 (សំឡេង) និងគុណភាព 360p–2160p
- ប៊ូតុងអាប់ដេត yt-dlp (Stable / Nightly) សម្រាប់ដោះស្រាយបញ្ហា TikTok
- ឯកសារត្រូវរក្សាទុកក្នុង **Downloads/VideoDownloader**

## បង្កើតឯកសារ APK (វិធីងាយបំផុត មិនចាំបាច់ដំឡើង Android Studio)
1. បង្កើតគណនី github.com (ឥតគិតថ្លៃ) ហើយបង្កើត Repository ថ្មីមួយ (Private ក៏បាន)
2. ដាក់ឯកសារទាំងអស់ក្នុងថតនេះ (រួមទាំងថត `.github`) ចូលក្នុង Repository
   (ចុច "Add file" → "Upload files" ហើយអូសថតទាំងអស់ចូល)
3. ទៅផ្ទាំង **Actions** → ជ្រើស "Build APK" → ចុច **Run workflow**
4. រង់ចាំ 5–10 នាទី រហូតមានសញ្ញាធីកបៃតង
5. ចុចលើការ build នោះ → ផ្នែក **Artifacts** → ទាញយក `VideoDownloader-APK` (ជា .zip) → ពន្លាយកឯកសារ `.apk`

## ដំឡើងលើទូរស័ព្ទ
1. ផ្ទេរឯកសារ `.apk` ទៅទូរស័ព្ទ
2. បើកវា ហើយអនុញ្ញាត "Install unknown apps" សម្រាប់កម្មវិធីដែលអ្នកប្រើបើក (Files / Chrome)
3. ដំឡើង រួចបើកកម្មវិធី

## បង្កើតដោយ Android Studio (ជម្រើស)
បើកថតនេះក្នុង Android Studio → រង់ចាំ Gradle Sync → Build → Build APK(s)។

## ចំណាំ
- ត្រូវការ Android 10 ឬថ្មីជាងនេះ (API 29+)
- ទូរស័ព្ទ 64-bit/32-bit ARM ទាំងពីរ (ស្ទើរតែទូរស័ព្ទទាំងអស់)
- សូមបើកកម្មវិធីទុកក្នុងពេលទាញយក (អេក្រង់នឹងភ្លឺជានិច្ចក្នុងពេលនោះ)
- បើ TikTok បរាជ័យ សូមចុច "អាប់ដេត yt-dlp" → Nightly ហើយសាកល្បងម្តងទៀត
- វីដេអូមានកម្មសិទ្ធិបញ្ញារបស់អ្នកបង្កើត សូមប្រើសម្រាប់ការរក្សាទុកផ្ទាល់ខ្លួន ឬខ្លឹមសារដែលអ្នកមានសិទ្ធិប្រើប៉ុណ្ណោះ
